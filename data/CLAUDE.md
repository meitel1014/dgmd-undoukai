## 出場者シートの形式（スプレッドシート・CSV 共通）

列がチーム、行が種目の表形式。A 列は空。パースは [src/extension/parseTeamsGrid.ts](../src/extension/parseTeamsGrid.ts)。

```text
,            ,りくおくん,ぽあるん,チョコパン,タクティス   ← B 列「チーム」の行: 主将名
,エリア制限  ,…,…,…,…                                 ← 種目ラベル行 = 1人目
,            ,…（2〜4人目）
,エリア無制限,…（4行）
,ナワバリ    ,…（4行。1人目は主将本人）
```

- B 列が `チーム` の行の C 列以降に主将名が並ぶ。空セルの列は無視する。チーム名は `{主将名}チーム`、ID は並び順の連番 `"1"`〜
- B 列が種目ラベル（`エリア制限` / `エリア無制限` / `ナワバリ`）の行から 4 行ぶんが、その種目の選手
- 位置ではなくラベルで探すので、行の追加・並べ替えに強い。セルは前後空白を trim、欠けたセルは空文字
- 種目ラベルが無い場合はその種目の選手を空文字にし、ログ警告を出す。`チーム` 行が無い場合はチーム 0 件

## Googleスプレッドシート連携仕様

### `data/sheets.json` の形式

```json
{
  "url": "https://docs.google.com/spreadsheets/d/XXXXXXXX/edit",
  "sheetTitle": "シート1"
}
```

`url` はスプレッドシートのURLをそのまま貼り付ければよい（IDを正規表現で自動抽出する）。`sheetTitle` はワークシート（タブ）名で任意。省略時・不一致時は先頭シートを使う。
読み込み範囲は `A1:Z200`（`getCellsInRange`）。

### サービスアカウントの準備（よくある詰まりポイント）

1. GCPでサービスアカウントを作成し、鍵（JSON）をダウンロードして `data/credentials/` 配下に配置する
2. 鍵JSON内の `client_email` を、対象スプレッドシートに**閲覧者として共有**する（共有を忘れると読み込みに失敗し、CSVへフォールバックする）
3. Google Sheets API がGCPプロジェクトで有効化されていることを確認する

読み込みに失敗した場合（鍵未配置・共有忘れ・API未有効化等）は `teams.csv` に自動フォールバックする。Dashboardの「設定｜チーム情報再読込」パネルから手動再読込もできる。
