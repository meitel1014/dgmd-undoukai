# デジ窓大運動会 スプラ3種目 配信ツール 設計書

日付: 2026-11-05

## 目的と背景

既存のスプラトゥーン3トーナメント配信ツール（ika-terrace-node）を、「デジ窓大運動会」の配信に使えるよう改修する。
大運動会は4チームが7種目＋サブ企画を戦うチーム対抗戦だが、**このツールが扱うのはスプラの3種目だけ**。

| 種目 | ID（本設計での識別子） | 形式 |
|---|---|---|
| 第5種目 ガチエリア（制限有） | `areaLimited` | トーナメント（3位決定戦あり）、全試合 BO3 |
| 第6種目 ガチエリア（無制限） | `areaUnlimited` | 同上 |
| 第7種目 ナワバリバトル | `turf` | 同上 |

**複数の種目を同時に実施することはない**（ユーザー回答。最初の「同時進行」という回答は撤回された）。一度に進行する試合は常に1つ。

**稼働構成**: 1台の PC で NodeCG を1つだけ動かし、OBS と操作担当者はそこに接続する（ユーザー回答）。

**状態の持ち方**（ユーザー回答）:
- **選択チーム（アルファ / ブラボー）は種目ごとに分けて持つ**。種目を切り替えると、その種目の対戦カードがそのまま残っている
- **勝利本数は全種目で1つを共有する**
- チーム情報（表示名など）は全種目で共有する

## スコープ

### やること
- スプラ3種目ごとに **Dashboard Workspace** と **battle Graphic** を1つずつ用意する
- 新しい形式の出場者スプレッドシートから、種目ごとの出場メンバーを読み込む
- 種目ごとの勝利本数（2本先取）を管理し、Graphic に表示する

### やらないこと（非ゴール）
- スプラ以外の種目とサーモンランは扱わない（OBS で直接チーム名を表示する運用）
- 総合ポイントの集計・表示
- 試合段階（準決勝 / 3位決定戦 / 決勝）の表示
- 優勝演出（champion）とチーム紹介（team-roster）
- レイアウト画像（ロゴ・バー類）の描画。画像は OBS の別レイヤーで敷き、Graphic は透過背景に文字だけを描く

### 削除する既存機能
次の機能は、コード、Replicant、スキーマ、パネル、Graphic、`package.json` の登録、配信ミドルウェア、データファイルの参照まで含めて削除する。

- ステージ自動認識（`src/extension/ocr/`、`detectedStage`、`sharp` 依存の処理、`data/screenshots`・`data/stages` の利用）
- ステージバンピック（`stageBanpick`、`stagePool`、`stageRule`、`rule`、`battle-stage-banpick` パネル、`stage-banpick` Graphic、`settings-stage-rule`、ステージアイコン配信）
- 試合段階（`matchStage`、`battle-match-stage` パネル、`regulationRounds` と `settings-regulation-rounds`）
- 実況・解説（`castCandidates`、`castMembers`、`cast-control`、`settings-cast-upload`、`cast`/`cast-replay` Graphic、キャストアイコン配信、`data/cast.json` の読み込み）
- ブキ・X ID などの選手個人情報（`weapons`、`xId`、`weapon_aliases.csv`、武器画像配信、選手情報登録フォームとの照合）
- 優勝判定（`champion`、`recomputeChampion`）、必要勝利数の設定（`winTarget`、`settings-win-target`）
- `champion` / `team-roster-*` Graphic
- 意気込み（`comment`）。新しいシートに該当データが無いため

`data/` 配下の画像やファイルはリポジトリから消さなくてよい（参照を外すだけ）。消すかどうかは実装時に判断してよい。

## チームとメンバーのデータ

### 出場チーム
主将は りくおくん / ぽあるん / チョコパン / タクティス の4人。チーム名は `{主将名}チーム`（例: `りくおくんチーム`）。

### スプレッドシートの形式
URL: https://docs.google.com/spreadsheets/d/1tgzMuNje2cot5RUShRaSNhxpRTIIxIi85Z-WftQZQuE/edit
（現在は一部が仮データ。りくおくん列の「ブックス」はダミー）

列がチーム、行が種目の、表形式のシート。A 列は空。

```text
,          ,りくおくん,ぽあるん  ,チョコパン,タクティス   ← 「チーム」行: 主将名
,エリア制限 ,…         ,…         ,…         ,…           ← 種目ラベル行 = 1人目
,          ,…         ,…         ,…         ,…           ← 2〜4人目（ラベル空）
,          ,…
,          ,…
,エリア無制限,…（4行）
,ナワバリ   ,…（4行。1人目は主将本人）
```

パース規則:
- B 列が `チーム` の行の C 列以降を、チームの並び（主将名）とする。チーム ID は列順の連番文字列 `"1"`〜`"4"`
- B 列に種目ラベル（`エリア制限` / `エリア無制限` / `ナワバリ`）がある行から、その行を含めて4行をその種目のメンバーとする
- 位置ではなくラベルで探す（行の追加や並べ替えに強くするため）
- 空セルは空文字の選手名として扱う。種目ラベルが見つからない場合は、その種目の4人を空文字にしてログ警告を出す

### 読み込み経路
- **主経路**: 既存の Google Sheets API ＋サービスアカウント方式を流用する。`data/sheets.json` は1シートだけを指す形式に変更する（`url` と、任意の `sheetTitle`）。申請フォームと選手情報登録フォームの2シート構成は廃止する
- **フォールバック**: `data/teams.csv`。**スプレッドシートを CSV でエクスポートしたものと同じ表形式**にする（パーサーは共通化する）。既存の列名ベースの CSV 形式は廃止する
- 既存と同じく、起動時の初期化は永続値が無いときだけ。設定 Workspace から「スプレッドシートから再読込」「CSV アップロード / 再読込」を行える
- **再読込時の選択の扱い**: チーム ID は列順で振るので、列が並べ替えられると ID の指すチームが変わる。再読込後、`selection` の各種目のアルファ / ブラボーの選択を、再読込前のチームの `name`（主将名）で新しい ID に付け替える。見つからない枠は `null` にする。勝利数はそのまま残す（Claude の判断）
- **旧データの移行**: Team 型と Replicant 構成が変わるため、旧 `db/` の値とは互換性が無い。移行コードは書かず、初回起動前に `db/` を削除する手順を README に記載する（Claude の判断）

### Team 型（変更後）

```ts
type EventId = 'areaLimited' | 'areaUnlimited' | 'turf';

type Team = {
  id: string;        // "1"〜"4"
  name: string;      // "りくおくんチーム"。編集禁止、Dashboard 表示用
  viewname: string;  // Graphic 表示用。初期値は name。Dashboard から編集可、<br> 等の HTML 可
  rosters: Record<EventId, [string, string, string, string]>; // 種目ごとの選手名4人
};
```

`viewname` は全種目で共通にする（チーム名は種目によって変わらないため）。`name` / `viewname` の使い分け（Graphic だけ `viewname`）と、`<Html>` コンポーネント経由のレンダリングは既存のルールを守る。

## 種目ごとの状態（Replicant）

| Replicant | 型 | 内容 |
|---|---|---|
| `selection` | `Record<EventId, { alpha: string \| null; bravo: string \| null }>` | 種目ごとの選択チーム ID。既存の `selection` を種目別の形に変更する |
| `winCount` | `{ alpha: number; bravo: number }` | 勝利本数。**全種目で共有**。既存のまま |

- 既存の挙動を引き継ぐ: **どの種目でも、チームを入れ替えたらその枠（アルファ / ブラボー）の共有勝利数を 0 に戻す**（Extension 側で一元管理）。同時に進行するのは1試合だけなので、この動きで問題ないと判断した（Claude の判断）
- 必要勝利数は全種目 **2本先取で固定**。勝利数は 0〜2 に収め、2 を超える加算は無視する
- 優勝判定はしない（champion 廃止）

### 勝利数の操作
- **HTTP**: 既存の `POST /result`（body: `{ "result": "alpha_win" | "bravo_win" | "reset" }`）をそのまま使う。OBS 側の設定変更は不要
- **Dashboard**: 各種目の Workspace から +1 / −1 / リセットできるようにする（手動補正用）。どの Workspace から操作しても同じ共有勝利数が変わる

## Dashboard

| Workspace | パネル | 内容 |
|---|---|---|
| エリア制限 | チーム選択 | アルファ / ブラボーのチームを4チームから選ぶ |
| エリア制限 | プレビュー編集 | 両チームの表示名（`viewname`）と、この種目の選手名4人を編集。勝利数の +1/−1/リセット |
| エリア無制限 | （同上） | |
| ナワバリ | （同上） | |
| 設定 | チーム情報再読込 | スプレッドシート再読込、CSV アップロード / 再読込 |

- 3つの Workspace のパネルは、既存の `_shared/` コンポーネントに `eventId` を props で渡す薄いラッパーにする
- 選手名の編集は `updateTeam` メッセージで、`rosters[eventId]` の該当選手だけを部分更新する。表示名の編集は全種目に反映される
- パネルの表示名は種目名を含めて区別できるようにする（例: `エリア制限｜チーム選択`）

## Graphic

種目ごとに1枚ずつ、計3枚の battle Graphic を作る（例: `battle-area-limited` / `battle-area-unlimited` / `battle-turf`）。中身は共通コンポーネントに `eventId` を渡すだけにする。

1920×1080、**背景は透過**。添付のレイアウト画像（OBS で下に敷く）の枠に文字を重ねる。
ユーザーから完成イメージのサンプル（ゲーム画面＋枠＋文字を合成したもの）を受け取っており、配置はそれに合わせる。

| 要素 | 位置（サンプル準拠） | 揃え・見た目 | 内容 |
|---|---|---|---|
| アルファ選手名 ×4 | 左下の黒バー4本（y 約 680〜962、1本の高さ 約 66px、間隔 約 72px）。文字の左端 x≈50 | 左揃え、白、約 48px | `rosters[eventId]` の4人 |
| ブラボー選手名 ×4 | 右下の黒バー4本（同じ y）。文字の右端 x≈1875 | 右揃え、白、約 48px | 同上 |
| アルファチーム名 | 左下の大きい黒バー（y 約 980〜1080、文字領域 x 約 75〜540） | 中央揃え、白、約 52px。FitText で自動縮小 | `viewname` |
| ブラボーチーム名 | 右下の大きい黒バー（文字領域 x 約 1380〜1845） | 同上 | 同上 |
| アルファ勝利本数 | 黄色アクセント部分（中心 x≈640、y≈1028） | 中央揃え、濃いグレー（バーと同じ #333 前後）、約 80px の数字 | 0〜2 |
| ブラボー勝利本数 | 青アクセント部分（中心 x≈1280、y≈1028） | 同上 | 0〜2 |

- チーム名の表示例: 「タクティスチーム」「ちょこぱんチーム」（サンプル）。`viewname` はひらがな表記などに編集して使われうる
- **フォントは「でらすこゴシック」**（ファイル名 `DelaSukoGothicOne-R`）。Graphic の全テキストに使う
  - 配信 PC（Windows）にはインストール済み（`C:\Users\MEITEL\AppData\Local\Microsoft\Windows\Fonts\DelaSukoGothicOne-R.ttf`）
  - `@font-face` で `local()` を優先し、見つからない場合はリポジトリ内に同梱したフォントファイルを読む（Claude の判断。別 PC で OBS を動かしても崩れないようにするため）
- サンプルの白文字には太字感と軽い縁取り・影がある。似せる程度でよく、最終調整は手動で行う
- 座標は上の値で仮置きする。微調整は手動で行う（既存方針と同じ。CSS クラスを付けて、位置は CSS で指定する）
- チームが未選択の枠は何も描かない
